# LXX Greek Source Workspace

Place public-domain or otherwise lawful source-text files here for fresh-translation work.

Suggested fields for source CSV rows:

- `ref`
- `book_code`
- `book_name`
- `chapter`
- `verse`
- `greek_text`
- `transliteration`
- `literal_gloss`
- `syntax_notes`
- `draft_translation`

Pilot file:

- `genesis_1_3_pilot.csv`

Keep copyrighted exports or sensitive local experiments out of tracked files.
Use ignored paths for anything private.
