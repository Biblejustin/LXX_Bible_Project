# 1 Enoch Witness Workspace

This directory is separate from the Greek deuterocanon workspace.

`1_enoch_charles_witness.csv` parses the public-domain R. H. Charles 1917
English translation of 1 Enoch from Ethiopic, preserving Charles's comparison
markers for Greek, Ethiopic, restored, interpolated, supplied, emended, and
corrupt text.

It is a witness/comparison workspace only. It is not imported into
`data/raw/lxx_deuterocanon/deuterocanon_full.csv`, the main Bible source rows,
or Logos output.

Refresh:

```sh
make build-enoch-witness
```
