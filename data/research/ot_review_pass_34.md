# OT Review Pass 34

Scope = conservative infinitive / ability grammar cleanup after watch queues were closed.

Status keys:
- `keep` = leave wording
- `keep-provisional` = leave for now, but still open
- `needs-logos` = pause for deeper lexical / apparatus check
- `needs-remap` = source verse-map / structural issue, not simple wording issue
- `revised` = wording changed in source or tracked review note

## Numbers 13:30
- status: `revised`
- change: `because being able, we shall be able against them` -> `because we are certainly able to prevail against them`
- reason: Greek repeats ability language in a hostile context; English needs a normal predicate while preserving the emphatic confidence.

## Deuteronomy 19:9
- status: `revised`
- change: `if you listen to do all these commands` -> `if you listen so as to do all these commands`
- reason: removes malformed English while preserving the hearing/obedience construction.

## Deuteronomy 28:58
- status: `revised`
- change: `If you do not listen to do all the words` -> `If you do not listen so as to do all the words`
- reason: same hearing/obedience construction as Deuteronomy 19:9.
