# Genesis 1-3 Workflow

Pilot aim:

- produce a fresh English rendering of Genesis 1-3 from Greek
- use local Logos resources for evidence
- keep private notes private
- keep final project public

Preferred workflow:

1. Read base Greek in `Genesis (Göttingen Septuagint I)`.
2. Check morphology in `Septuagint with Logos Morphology`.
3. Check lexical range in `Lexham Research Lexicon of the Septuagint`.
4. Check syntax or idiom in `Grammar of Septuagint Greek`.
5. Check variants in `Septuaginta: Apparatus Criticus`.
6. Record only paraphrased findings in tracked CSV files.
7. Keep detailed personal notes in private Logos notebooks or ignored local files.

Per-verse checklist:

- Greek text entered
- transliteration entered if useful
- literal gloss entered
- syntax note entered
- draft translation entered
- main decision rows logged
- variant impact noted if needed

First pass target:

- Genesis 1:1-3
- then Genesis 1:4-31
- then Genesis 2
- then Genesis 3
