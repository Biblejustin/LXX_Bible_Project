# OT Review Pass 33

Scope = malformed auxiliary / predicate grammar cleanup.

Status keys:
- `keep` = leave wording
- `keep-provisional` = leave for now, but still open
- `needs-logos` = pause for deeper lexical / apparatus check
- `needs-remap` = source verse-map / structural issue, not simple wording issue
- `revised` = wording changed in source or tracked review note

## Jeremiah 15:20
- status: `revised`
- change: `make you to this people as fortified bronze wall` -> `make you for this people as a fortified bronze wall`
- reason: removes malformed English while preserving the people/wall comparison.

## Genesis 32:25
- status: `revised`
- change: `was not able against him` -> `could not prevail against him`
- reason: Greek δύναμαι πρός in a wrestling context is naturally expressed as prevail against.

## Psalms 128:2
- status: `revised`
- change: `were not able against me` -> `could not prevail against me`
- reason: same δύναμαι πρός construction in a hostile context.

## Jeremiah 45:5
- status: `revised`
- change: `king was not able against them` -> `the king could not oppose them`
- reason: keeps the king's inability before the officials without malformed English.

## Nehemiah 5:9
- status: `revised`
- change: `Not good is the word which you are doing` -> `The thing you are doing is not good`
- reason: preserves the rebuke while moving from word-for-word order to clear English.

## 1 Samuel 20:29
- status: `revised`
- change: `there is for us a tribal sacrifice` -> `we have a tribal sacrifice`
- reason: Greek possession idiom needs normal English possession.

## 2 Kings 4:2
- status: `revised`
- change: `what there is for you in the house` -> `what you have in the house`
- reason: Greek possession idiom needs normal English possession.

## Lamentations 3:45
- status: `needs-logos`
- focus: καμμῦσαι / rejection phrase
- reason: `made us to blink and be thrust away` is mechanically suspicious, but the lexical phrase needs deeper review before changing.
