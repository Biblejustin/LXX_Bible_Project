# OT Review Pass 36

Scope = Nehemiah word/matter idiom cleanup.

Status keys:
- `keep` = leave wording
- `keep-provisional` = leave for now, but still open
- `needs-logos` = pause for deeper lexical / apparatus check
- `needs-remap` = source verse-map / structural issue, not simple wording issue
- `revised` = wording changed in source or tracked review note

## Nehemiah 2:19
- status: `revised`
- change: `What is this word you are doing?` -> `What is this thing you are doing?`
- reason: Greek ῥῆμα can carry matter/thing sense; English `word you are doing` is malformed because the object is the wall work.

## Nehemiah 13:17
- status: `revised`
- change: `What is this evil word which you are doing and profaning the Sabbath day?` -> `What is this evil thing you are doing, profaning the Sabbath day?`
- reason: same word/matter idiom; revised wording preserves the charge while removing malformed English.
