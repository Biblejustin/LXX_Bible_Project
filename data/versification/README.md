# Versification Mapping Data

This directory stores compact verse-reference mapping data used only for
Logos-facing bridge outputs.

- `lxx_to_eng_map.json` maps Septuagint-style verse references to standard
  English/Protestant Bible references.
- Source: `versification-utils` 0.0.1, `standard_mappings/lxx.json` and
  `standard_mappings/eng.json`.
- Upstream: <https://github.com/jcuenod/versification_utils>
- License: MIT.

The map is used to make existing Logos notes anchored to MT/English Bible
references appear in a Personal Book built from LXX-numbered source rows.
